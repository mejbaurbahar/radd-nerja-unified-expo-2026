The Market Paradigm Shift

Communication Channels Become Selling Channels

Why the traditional "support-only" chatbot model is dead, and how Radd + Nerja transforms messaging into a revenue engine.

❌

Traditional WhatsApp / Live Chat (The Cost Center)

  • Reactive Only: Customer has an issue, asks a question, and leaves.
  • Zero Direct Revenue: Generates no measurable sales attribution for the business.
  • Disconnected from Storefront: The bot has no awareness of what the customer browsed, added to cart, or abandoned on the website.
  • High Drop-off: Forces customers to open external links and fill web forms to complete purchases.
✅

Radd + Nerja Unified Platform (The Revenue Flywheel)

  • Proactive AI Sales: Support bot cross-sells, recommends items, and closes transactions directly.
  • In-Chat Purchasing: Native WhatsApp catalog checkout and booking confirmation without leaving the chat.
  • NerjaTag Behavioral Intelligence: Automatically detects when a visitor lingers on a cart or product page.
  • Instant Recovery Triggers: Automatically fires a WhatsApp message with a promo code to close the sale.

Event Tracking Engine: Auto-Heuristics + Custom Tags

How NerjaTag recognizes "Add to Cart" buttons automatically, and how custom websites are tagged with zero code.

1. Layer 1: Automated DOM Heuristics

Zero configuration required. Injected <script> analyzes clicks and mutations:

  • Text Matching: Matches button labels (Add to Cart, أضف للسلة, Buy Now, حجز).
  • Class & ID Regex: Identifies classes like .btn-cart, #addToCart, [name="checkout"].
  • Schema.org Microdata: Automatically extracts item price, currency (SAR), and SKU from JSON-LD.
Live Test Button:

2. Layer 2: Custom HTML Tagging Standard

For custom websites with non-standard classes, developers add simple data attributes:

<!-- Client adds standardized HTML attribute -->
<button 
  data-nerja-event="add_to_cart"
  data-nerja-item="Premium Silk Abaya"
  data-nerja-price="450"
  data-nerja-currency="SAR">
  Confirm Selection
</button>

NerjaTag auto-attaches listeners to any element with [data-nerja-event] without writing custom JavaScript.

High-Throughput Database Architecture

  • AWS SQS / Kafka Ingestion Buffer: Absorbs 50,000+ requests/sec with <15ms latency, decoupling database writes.
  • Monthly Table Partitioning: Events partitioned by nerja_events_YYYY_MM, ensuring sub-millisecond query indexing.
  • Hot vs. Cold Storage: 30-day active session intent stored in Redis/PostgreSQL; cold data archived to S3 Parquet.
💡 Architecture Decision: Database sharding guarantees multi-tenant isolation across 713+ companies without table locking.
